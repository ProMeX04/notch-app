# Milestone v1.0: Notch Portal Migration - Auth Phase

**Status:** ✅ SHIPPED 2026-05-31
**Phases:** 1-3
**Total Plans:** 6

## Overview

This milestone accomplishes the complete migration of the Authentication and Session layer of the Notch Portal from Next.js to Go (Chi + pgx/v5) and Vite React (TanStack Router + TypeScript), ensuring 100% response and behavioral parity.

## Phases

### Phase 1: Go Auth Backend APIs

**Goal**: Implement all auth-related endpoints in the Go API server.
**Depends on**: Nothing
**Plans**: 3 plans

Plans:
- [x] 01-01: Implement Auth DB Repositories & Base endpoints (Login, Register, Logout)
- [x] 01-02: Implement Sessions Management and Revocation endpoints
- [x] 01-03: Implement Google OAuth & Google Drive handoff APIs

**Details:**
- Database queries and user model updates to support hashed passwords and stateful session tracking.
- Session auditing and revocation handlers to support multi-device user tracking.
- Google OAuth 2.0 authorization code exchange and AES-256-GCM desktop deep-link handoff encryption.

### Phase 2: React Frontend UI Migration

**Goal**: Connect React views in `portal/web` to the Go backend APIs.
**Depends on**: Phase 1
**Plans**: 2 plans

Plans:
- [x] 02-01: Connect Login & Google OAuth views in React
- [x] 02-02: Connect Account & Sessions Management views in React

**Details:**
- Full implementation of Login and Account pages in Vite React.
- Interactive device and active session tables enabling device trusting, untrusting, and revocation.
- PKCE authentication flow and custom success/redirection UX components.

### Phase 3: Dual-Server Setup & Parity Testing

**Goal**: Set up concurrent running and test parity between Next.js and Go + React.
**Depends on**: Phase 2
**Plans**: 1 plan

Plans:
- [x] 03-01: Setup concurrently running dev scripts & execute parity check suite

**Details:**
- Development scripts orchestrating concurrently running API and UI servers with signal-trap cleanup.
- Programmatic parity tests comparing Next.js production backend output structures with Go endpoint responses.

## Milestone Summary

**Key Decisions:**
- **Decision:** Focus on Auth Phase first. (Rationale: Auth is the structural foundation; migrating it first secures subsequent feature migrations).
- **Decision:** Horizontal Layers Strategy. (Rationale: Decouple backend development from frontend UI migration).
- **Decision:** Concurrent Local Setup. (Rationale: Running Next.js and Go/Vite side-by-side enables direct verification and live-contrast testing).

**Issues Resolved:**
- Standardized JWT layout, encryption signatures, and Neon database sessions schema.
- Resolved local production cookie auth failures by disabling standard Secure cookie flag on localhost.
- Unified response styles, JSON error layouts, and query parameters verification to guarantee transparent client handoffs.

**Issues Deferred:**
- Payments / VNPay migration (deferred to Milestone 2.0).
- Pro Capabilities check and API endpoints (deferred to Milestone 2.0).
- Admin Dashboard features (deferred to Milestone 2.0).
- Gemini Live token and session orchestration (deferred to Milestone 2.0).

**Technical Debt Incurred:**
- Login/register routes lack HTTP rate limiting.
- Frontend CSS definitions are appended directly to globals.css rather than systematically styled via Tailwind.
