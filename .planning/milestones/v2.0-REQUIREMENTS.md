# Requirements: Notch Portal Migration - Feature Phase (Milestone v2.0)

**Defined:** 2026-05-31
**Core Value:** Ensure complete, secure, and reliable payments, capability gating, admin console, and Gemini Live APIs parity on the new Go + Vite React stack to enable seamless user transitions.

## v1 Requirements

Requirements for this milestone release. Each maps to roadmap phases.

### Payments & billing (PAY)

- [x] **PAY-01**: Authenticated user can initiate a Pro upgrade checkout session via Go backend (`POST /api/payments/vnpay/create`), generating and returning the signed VNPay payment URL.
- [x] **PAY-02**: Go backend processes VNPay IPN callbacks (`GET /api/payments/vnpay/ipn` and `GET /api/payments/vnpay/return`), performing SHA-512 HMAC signature verification, checking order amounts, and updating transaction/user status in PostgreSQL.
- [x] **PAY-03**: React Frontend Profile page integrates with checkout creation and initiates redirect to VNPay interface.

### Capabilities & Entitlements (CAP)

- [x] **CAP-01**: Go backend projects public capability list and rules (`GET /api/capabilities`), mapping whether features like Gemini Live are Pro-only or enabled.
- [x] **CAP-02**: React Frontend fetches capability rules dynamically, adjusting landing/upgrade UI page layouts and links.
- [x] **CAP-03**: User permission policy is loaded during login/refresh session responses, mapping boolean entitlements based on the user's Pro status.

### Admin Dashboard (ADM)

- [x] **ADM-01**: Admin endpoints for listing capabilities (`GET /api/admin/capabilities`) and updating capability overrides (`PATCH /api/admin/capabilities`) are fully functional.
- [x] **ADM-02**: Admin endpoint for restoring capabilities to manifest defaults (`POST /api/admin/capabilities/restore`) is fully functional.
- [x] **ADM-03**: Admin endpoints for listing all users (`GET /api/admin/users`) and updating a specific user's status (`PATCH /api/admin/users/{id}`) are fully functional.
- [x] **ADM-04**: React Frontend Admin console renders tables for capabilities, configuration forms, user management tables, and capability restoration buttons.

### Gemini Live (GEM)

- [x] **GEM-01**: Go backend handles secure Gemini Live session token requests (`POST /api/gemini-live/token`) with verification of Pro eligibility.
- [x] **GEM-02**: Go backend exposes Gemini Live supported models list (`GET /api/gemini-live/models`) and service health status (`GET /api/gemini-live/health`).

## Out of Scope

- Live WebSocket audio streaming in Go backend — Deferred to subsequent milestone to keep focus on web interface and token APIs.
- Subscription billing support (recurring cards) — Deferred, only single upgrade payments are supported in parity.
